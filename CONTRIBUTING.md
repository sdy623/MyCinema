# Contributing

Contributions must be original work that the contributor has the right to license under Apache-2.0.

Do not submit:

- decompiled, copied, reconstructed, or modified WaterFrames, WaterUI, WaterMedia, Minecraft, Iris, or Sodium code or assets;
- third-party JARs, native libraries, or generated class files;
- Mixins that reproduce substantial upstream implementation;
- assets without a documented author, source, and license;
- credentials, tokens, personal paths, world saves, logs, or private test data.

Compatibility patches should target an exact upstream version, explain why a public event or API is insufficient, and include a focused regression test.
